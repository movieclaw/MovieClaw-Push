# 安全问题报告 / Security Policy

发现安全问题请**不要**开公开 Issue，用下面任一方式私下告诉我们：

- GitHub 私密报告：仓库的 Security → Report a vulnerability
- 邮件：service@movieclaw.io

修复发布前请不要公开细节。

Please do **not** open a public issue for security problems. Report privately via
GitHub (Security → Report a vulnerability) or email service@movieclaw.io,
and keep the details private until a fix is released.
